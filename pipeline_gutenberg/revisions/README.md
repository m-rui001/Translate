# 已有译作复校记录

逐段对照原文，核对人物、动作、时间和反复出现的意象，再读中文的叙述和对话。每部记录读到的章节，未复校的章节继续使用历史译稿。

## 《茵梦湖》

已按德文底本逐段复校全书十章，共 302 个正文段落。

- 开头老人抬起手杖示意女管家先别点灯，结尾托她把灯放上桌。两处的动作和说话声调相互照应。
- 把主人公的译名统一为「莱因哈德」。伊丽莎白在信中提到的 Hänfling 是赤胸朱顶雀，和后来鸟笼里的金丝雀有别。[《中国生物多样性红色名录·脊椎动物卷》](https://www.cqna.gov.cn/bm/qsthjj/zwgk_59968/zfxxgkml/jczwgk/hjgl/zrst/202306/W020230616560688384534.pdf)
- 恢复地下酒馆里把香槟递给弹琴姑娘的年轻人，改正窗内透出的是圣诞树上的烛光。在《林中》保留四节诗，在圣诞夜一章保留歌、诗的分行。
- 德文底本开头附有题名和目录，旧 EPUB 曾将其压成正文第一章。新版 EPUB 的目录直接列出小说十章，每章标题只出现一次。[古登堡计划德文底本](https://www.gutenberg.org/ebooks/6651)
- 把《伊丽莎白》重现的两句歌与圣诞夜的唱词统一，恢复渡湖前闷热的天气，清理雷雨一句的德文残留。末章所见的白睡莲与莱因哈德夜游时所见的白睡莲保持一致。
- 保留德文底本的九条编注并加入双向跳转。末次散步两人认出的 Erika 译作「欧石南」。[中国科学院昆明植物研究所的欧石南属介绍](https://kbg.kib.cas.cn/kxjy/kpzs/kpwz/202303/t20230309_599513.html)

运行 `python -X utf8 pipeline_build/build_gutenberg.py immensee` 重建。复校后的全文、章节标题、诗行标记和编注保存在 `immensee.json`。重建只依赖仓库文件。
