# 坟头草译 · 文学翻译流水线

把公版外文长篇小说、诗集与短篇集，经「抽取 → 分单元翻译 → 术语统一 → 文风校订 → 组装 → 质检」流水线译成中文，产出 EPUB。

## 仓库内容

- `pipeline*/`：各阶段代码。`pipeline` 为主流水线（抽取、翻译、术语表、引号与体例修复、组装），`pipeline_new`/`pipeline_build`/`pipeline_overhaul` 为换代与整书重建，`pipeline_fix`/`pipeline_polish` 为定向校订，`pipeline_pub`/`pipeline_gutenberg`/`pipeline_private`/`pipeline_proust`/`pipeline_whale` 为具体书系的工作流。
- `out/`：65 本成品 EPUB。
- `MEMORY.md`：工程日志（决策、失败模式、验收数字）；`REPAIR_2026-*.md`：逐轮修复记录；`API_STATUS.md`：模型通道实测状态；`experience.md`、`PIPELINE_REVIEW.md`：流程复盘。

## 流水线要点

1. **抽取**：从 EPUB/PDF/TXT 还原章节与段落，保留原文分段。
2. **分单元翻译**：按段/场景切块，逐块请求并缓存；对空译、段数不符、回退英文的块自动重试或换模型。
3. **术语与专名**：抽取人名/地名候选，按上下文判定异写是否同一实体，统一译名。
4. **文风校订**：清除北方口语、网络语与机械四字格；只做最小改动，段数与长度变动设阈值。
5. **组装与质检**：EPUB3 结构、目录、版权页、引号与省略号体例检查；成品统一放在 `out/`。

## 运行

- Python 3.13，第三方依赖以各 `pipeline*/` 目录中的 `import` 为准（主要为 `requests`）。
- 模型通道全部走环境变量，仓库内不保存密钥：
  - `FREEAI_BASE` / `FREEAI_KEY`：本地 OpenAI 兼容网关（默认 `http://127.0.0.1:8317`）。
  - `CSSM_KEY`：cssmapi 兼容端点（如使用）。
  - `MODELS_JSON`：本机模型清单路径（默认 `models.json`）。
- 各工作流脚本多为一次性工具，路径与书名按当时的 `work_*/` 目录写死；复用时需按新目录调整。

## 质量与局限

机器翻译为主，辅以规则校验与抽样校订。已尽量统一术语、体例与分段，但不保证译文准确、完整或符合出版标准；不要把本仓库的译本当作可靠引用来源。
