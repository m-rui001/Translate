# 堡垒

马塞尔·施沃布（Marcel Schwob）

苦闷和恐惧都到了极点。到处是弹片撞来弹去的金属声，怎么也不停。弹头在半空迸裂，呜咽起来，像风弦琴若有若无的声音，叫人冷到骨头里。四下沉在夜里，一片深黑，只有走廊、拱顶和护壕通道的入口划出几道更浓的黑影。

装甲板丁当一响，你才知道头顶有通风口或透气小窗。高高的穹顶用四面倒角的拱心石合拢。沿着拱棱，隔一段路才有一只微弱发亮的灯泡，只照见三块石头交接的缝。电池已经快耗尽了。

狭窄的通道穿过厚厚的混凝土，绕着方院转。斜斜并排封住窗洞的粗铁条阵阵轰鸣，逼得人太阳穴发紧，不由得加快脚步。再往中央去，黑暗的楼梯上满是碎玻璃，听得见绞盘呻吟，夹着操纵泵压低的叹息。

再高些，炮班沉重的喘息沿窄窄的铁皮楼梯传上来。炮塔从轴上抬起，擦着齿圈转动，链条吱嘎作响。

透过巨大圆筒的缝隙，借一盏油腻的灯，能看见两门一模一样的炮并排架在白色炮架上。突然，井道里响起一声“开火”。几个斑点般的人影紧贴圆筒，靠着各自的掩体，随它转动。四下一静，只有碎铁砸在穹顶上。随后暗处传来一声“按下”，炮塔在两声爆响中震颤。

有人经过，只觉一阵气流，衣角一擦。有时一队人迈着整齐的步子，沿走廊下到弹药井。还有人搬走备用的厚板、垫木和半截梁木，送往炮台。有的收拾采石用的绞盘，找起重架的配件，有的解开苫在长身管一五五毫米炮上的柏油篷布。那些炮在走廊里沉睡。

人们摸黑弓着腰走了太久，两手在石墙上磨破，指头干重活也磕伤了。他们仿佛几匹累坏的老马，沉沉地往前挪，黯淡的眼里尽是听天由命的神色。

甬道里、炮塔上和外围炮台还有些动静，回不到露在蓝天下的中央院落。堡垒司令的住所一带早已没了人影。

被围以来，人人各有定下的差事，像在铁甲舰上一样。军需官守在库房，不停地开桶验看咸猪肉，打开装满面粉的马口铁箱，撬开罐头，兑稀酒精，拔下大桶的塞子，用取酒管尝一尝酒。

如今储粮的拱室也空了，存煤同样耗尽。煤末泡在最后几摊发红的水里，几块硬饼干在松脱的门铰旁发烂。

两个士兵敲门进来报告，说电报线断了，电话听筒没了声，光学电报机也给炸得粉碎。司令耸了耸肩。大约已没什么指望，可他那副浅蓝眼镜底下看不出异样，短短的白胡子也丝毫没颤。

堡垒失去了联络。在野地里作战的那个师也已经受了威胁。拼着最后一线希望发个求援信号，也许还有人接得到，可眼下什么手段都用不上了。他房间里的彩绘是一名工兵在太平年月得人照拂时画的，如今受潮，正一点一点剥落。他望着片片翻起的灰泥，想起余下那几天，决意撑住。

他抬起头，两个士兵还在手里转着军帽。两个人都来自布列塔尼的罗斯波尔登，一个叫加奥纳克，一个叫帕拉里克。

加奥纳克一张脸薄得像刀刃，棱角分明，满是皱纹，骨架过长，关节又粗。另一个还没长胡子，睫毛近乎白色，眼睛清亮，笑起来像个小姑娘。开口的正是他，话说得有些迟疑。“长官，我跟加奥纳克来问问，您手上也许有封信要送？我们能送到。路我们熟，对吧，加奥纳克？”

工兵司令想了片刻。这当然不合规矩，况且他手下显然缺人。不过生路兴许就在这儿，舍得两条命，也许能救一百五十条。他坐到桌前，皱着眉写起来。写完后，他封好信，盖章签押，叫来伙夫，吩咐备足两份口粮和一小杯烧酒。随后他起身，同两个士兵握手。

“去吧，”他说，“你们的弟兄感谢你们。”

加奥纳克和帕拉里克穿过漆黑的走廊，从备用炮架旁经过，从一堆堆空弹壳间过去。已没有散装火药，也没有木引信，弹壳便空着。走到胸墙边，两人给倒地破裂的装土篓绊了一下。天已经黑了，只有敌人的沉寂能告诉人这一点。换下岗来的士兵挨个进了拱室，围着一截旧蜡烛，裹着毯子还直打战。

行军床上挂着枪架，一齐在白墙上投下怪诞的影子，像一座巨大火炉的栅栏。

两个人带上一把左轮手枪，离开房间，沿中央通道下去，叫人推开铁门。链条已经上了油，吊桥徐徐降下。他们走进寒夜，头顶悬着冰冷的星星。高五百米的台地上，风吹过断裂的电报线，呜呜作响。那凄凉的声音仿佛悬在空无一人的台地上空。

坡上的灌木簌簌抖动。远一点，废采石场的一座座黑土丘夹着道路。加奥纳克和帕拉里克一头钻进去，径直走到西端，好进树林。谷里横着一座桥，那条谷地把台地同山最外侧的支脉隔开。桥上应该有一队法国人驻守，这么显眼的要地，想必不会没人管。

隔着榛树丛，听得见河水在谷底低低地响。下面那条路上，两道深深的车辙都浸在雾里。两个布列塔尼人踩着满地枯叶，越走越快。他们都觉着天快亮了。

帕拉里克压低声音说。

“加奥纳克，我妈你认识吧？在罗斯波尔登开磨坊的那个。打我当兵去，就没见过她，也没见过家里那两个小的。你长得高，你有力气……”

加奥纳克把手搭在他肩上，答道。

“快到了。要是有人追来，你又走不动，我能背你一段。”

“我说的不是这个，”帕拉里克接着说，“死我倒不怕。我就是想，罗斯波尔登那间小屋，往后只剩我妈一个人了。荒地上那风，你也听过，吹起来多叫人心酸。她可怎么过呀？离这儿又那么远，咱们也没法子。我就想让你陪着我。你也是罗斯波尔登人。两个同乡结着伴，能走很远呢，何况咱俩又这么要好。”

“停，”加奥纳克说，“到尽头了。”

再走几步，树林边上陡然裂开一道深峡。两人探出头，河边微明的路上，隐约看见一团团人马经过，朝台地的斜坡移动。近处听得见马匹喘着气爬坡。

“跑回去，”加奥纳克说，“他们打来了。你去东炮台，我去西炮台。咱们总有一个能跑到。”

帕拉里克折回那条低低的小路，顾不得累，拔腿就跑。他跑得那么急，念头也像在脑子里一跳一跳。林子上头开始发白了，右边一簇簇树尖染上淡红。风比先前冷，叶子在风里摇。天顶的颜色淡了下去，看样子会是个好天。

快到采石场时，帕拉里克听见矮树丛那边隐隐有金属碰响，又有压低的脚步声。他扑进灌木，侧身躺着，睁大双眼。一片片湿蛛网打在脸上，他一动也不动。有人走过，披着大衣，在晨雾里仍是一团暗影。他们散开了队形向坡上走，像草地上一道会移动的折线。

主力多半在另一面攻，这些人想必是预备队。他们在林边停下，借地面一道褶皱藏住身形，三三两两拄着枪直喘。帕拉里克没法从他们眼前跑回堡垒。他想，要是他们继续往前，自己绕过斜坡就能早一点赶到。只盼加奥纳克来得及报信。

仿佛突然接到一个看不见的命令，士兵转向列队，沿坡下去。帕拉里克正要一转身冲出去，肚子里却猛地一阵剧痛。他仰面倒下，拳头攥紧，两臂半伸。一个跟在队伍后头的小贩瞧见水壶盖闪光，便用一把丢在矮树丛里的刺刀戳了过去。他掏空帕拉里克的口袋，小跑着走了。

血涌出来，鼓着大泡。小个子的布列塔尼人面如土色，眼睛向上翻。太阳越过斜坡，照见一队队分散的士兵还在往前走。

可就在这时候，堡垒那边传来几声闷响，炮弹在台地上炸开了。大铜炮低低地吼着，哈奇开斯和诺登费尔特的炮声一阵接一阵，滚过壕沟。小兵的眼睛还看得见堡垒。那些齐整的黑线映在天上，装甲穹顶转着，喷出两股烟。他想起加奥纳克，心里慢慢暖过来。为了罗斯波尔登，他心里欢喜。
